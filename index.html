MiScanner_Web (v9.0)

Python 3 Reconnaissance OSINT Engine
Código Fuente

Función Principal

Automatizar las fases críticas de reconocimiento pasivo y activo (*Footprinting*) sobre aplicaciones web expuestas para delimitar perímetros de red y vulnerabilidades lógicas preliminares.

Funcionalidades Clave

Web Crawling Inteligente

Mapeo algorítmico recursivo de directorios ocultos, indexación de archivos y descubrimiento de endpoints internos.

Extracción OSINT

Recolección y análisis de cabeceras HTTP de servidores, identificación de tecnologías obsoletas y fugas de metadatos.

ScannerVulnerabilidades (v9.0)

Pentesting Suite OWASP Top 10 Automation
Código Fuente

Función Principal

Framework modular parametrizado para la inyección controlada de cargas y stress-testing sobre puntos de entrada interactivos, validando la solidez de las defensas web.

Funcionalidades Clave

Fuzzing Temático OWASP

Detección proactiva de inyecciones SQL (SQLi), Cross-Site Scripting (XSS) y Local File Inclusion (LFI) mediante diccionarios dinámicos.

Auditoría de Fuerza Bruta

Módulos de autenticación de red acoplados nativamente con diccionarios optimizados para auditar la robustez de credenciales.

Reportes de Hardening

Consolidación instantánea de vectores descubiertos estructurados de manera cronológica en logs locales ordenados por IP.
